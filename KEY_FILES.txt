Project Structure:

    ├── web/app.py                  <- Main Flask app
    ├── templates/                  <- HTML templates
    │   ├── base.html               <- Master template
    │   ├── index.html              <- Homepage

    │   ├── category.html           <- Category filter
    │   ├── article.html            <- Article detail
    │   ├── about.html              <- About page

    └── requirements.txt            <- Dependencies

To Start:
  1. cd /sessions/friendly-affectionate-meitner/kronpapir
  2. pip install -r requirements.txt
  3. cd web && python app.py
  4. Visit http://localhost:5000

Key Routes:
  / - Homepage
  /local - Local news
  /national - National news
  /categorie/<cat> - By category
  /articol/<id> - Article detail
  /despre - About
  /api/articles - JSON API
