ROUTES AVAILABLE
================
GET  /                    - Homepage
GET  /local              - Local news
GET  /national           - National news
GET  /categorie/<cat>    - By category
GET  /articol/<id>       - Single article
GET  /despre             - About page
GET  /api/articles       - JSON API
*    /404                - 404 error
*    /500                - 500 error


DATABASE STRUCTURE (JSON)
========================
Each article must have:
{
  "id": "unique-id",
  "title": "Article Title",
  "excerpt": "Short summary",
  "content": "Full HTML content",
  "category": "local|politica|economie|cultura|sport|sanatate|social|mediu",
  "date": "YYYY-MM-DD",
  "source": "Publication Name",
  "type": "local|national",
  "author": "Author Name (optional)",
  "image": "URL to image (optional)",
  "url": "Original article URL (optional)"
}

QUICK START
===========
1. cd /sessions/friendly-affectionate-meitner/kronpapir
2. pip install -r requirements.txt
3. Place JSON files in data/processed/
4. cd web && python app.py
5. Open http://localhost:5000
